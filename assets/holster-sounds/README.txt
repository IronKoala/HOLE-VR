User-supplied HOLE holster sounds, rendered from the supplied Audacity 4 projects.

Drawing.aup4    -> draw.wav
Holstering.aup4 -> holster.wav
Hood-close.aup4 -> hood_close.wav
hood-open.aup4  -> hood_open.wav

Saved visible clips and bass/treble/output-gain settings were retained.
All four were attenuated together by 17.3409 dB to prevent output clipping.
The projects themselves were not modified or included in this package.

Format: mono, 44100 Hz, 16-bit PCM WAV. Keep the filenames above.
Install in HOLE/HOLE/Binaries/Win64/hole-vr/sounds/holster.
The source build copies this folder next to dxgi.dll automatically.
Source projects are user-provided assets; no third-party sound library was used.
